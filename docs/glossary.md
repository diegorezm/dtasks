# Glossary

- **Overview**: The workspace-level dashboard route at `/dashboard/:workspaceId/`.
- **Projects sidebar item**: Workspace navigation that opens the full Projects page and contains an expandable list of recently opened projects.
- **Recent projects**: Up to five projects whose task boards were most recently opened in the current browser for a specific workspace.
- **Workspace owner**: The single internal user responsible for workspace ownership and ownership transfer.
- **Workspace admin**: An internal user who can manage workspace settings, members, projects, and tasks without controlling ownership.
- **Workspace member**: An internal contributor who can create and update projects and tasks without managing workspace access.
- **Workspace viewer**: An internal user with read-only access to workspace projects and tasks.
- **Customer**: A user with separate, project-scoped portal access; never a workspace role.
- **Permission**: A stable backend capability key granted by a role and enforced at the Convex boundary.
